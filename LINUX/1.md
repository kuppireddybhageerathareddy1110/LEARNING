For an **SRE interview (Media.net or similar)**, you should know not just the names of the directories, but **why they exist, what they contain, and common interview questions**. Here's a detailed explanation.

# Linux Directory Structure

Linux follows a **hierarchical directory structure**, meaning everything starts from the **root directory (`/`)**. Unlike Windows, Linux does not have drives like C: or D:. Every file, directory, device, and process is part of one directory tree.

```
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── srv
├── sys
├── tmp
├── usr
└── var
```

---

# 1. `/` (Root Directory)

The **root directory** is the top-most directory in Linux.

* Every file and directory starts from `/`.
* Similar to the root of a tree.
* All mounted file systems appear under this directory.

Example

```
/
├── home
├── etc
├── usr
├── var
```

Commands

```bash
pwd
```

Output

```
/
```

Move to root

```bash
cd /
```

Interview Question

**Q: What is the root directory?**

Answer:
It is the top-level directory of Linux from which all other directories originate.

---

# 2. `/home`

Contains home directories for normal users.

Example

```
/home
    ├── john
    ├── alice
    └── bob
```

If the username is **john**

```
/home/john
```

contains

```
Documents
Downloads
Desktop
Music
Pictures
```

Command

```bash
cd /home
ls
```

Purpose

* Personal files
* User settings
* Downloads
* Documents

---

# 3. `/root`

Home directory of the **root (administrator)** user.

Not the same as `/`.

```
/root
```

Only root can normally access it.

Example

```bash
sudo su
cd /root
```

Interview Question

Difference between `/` and `/root`?

Answer

```
/      → Root directory of Linux

/root  → Home directory of root user
```

---

# 4. `/etc`

Stores almost all **system configuration files**.

Contains

```
/etc/passwd
/etc/shadow
/etc/hosts
/etc/fstab
/etc/ssh/
```

Important Files

### passwd

Stores user account information.

```
cat /etc/passwd
```

Example

```
john:x:1000:1000:John:/home/john:/bin/bash
```

---

### shadow

Encrypted passwords.

```
cat /etc/shadow
```

Only root can read.

---

### hosts

Maps hostname to IP.

```
127.0.0.1 localhost
```

---

### fstab

Controls filesystem mounting during boot.

---

### ssh

Contains SSH configuration.

```
/etc/ssh/sshd_config
```

Interview Question

Where are configuration files stored?

Answer

```
/etc
```

---

# 5. `/bin`

Contains essential user commands.

Examples

```
ls
cp
mv
cat
echo
pwd
mkdir
rm
```

Command

```
which ls
```

Output

```
/bin/ls
```

These commands are needed even if the system is in single-user mode.

# 6. `/sbin`

Contains system administration commands.

Examples

```
reboot
shutdown
mount
fsck
fdisk
```

Usually used by root.

Example

```
which shutdown
```

Output

```
/sbin/shutdown
```

Difference

```
/bin
Normal user commands

/sbin
System administration commands
```

---

# 7. `/usr`

Largest directory.

Contains installed software.

Subdirectories

```
/usr/bin
/usr/sbin
/usr/lib
/usr/share
```

Example

```
python
gcc
java
vim
```

Installed applications are mostly here.

Think of `/usr` as the place where most user-installed packages live.

---

# 8. `/var`

Variable data.

Files continuously change.

Contains

```
Logs
Mail
Cache
Print queue
Database files
```

Most important

```
/var/log
```

Examples

```
/var/log/messages
/var/log/syslog
/var/log/auth.log
```

View logs

```
tail -f /var/log/syslog
```

SRE Interview Question

Where do Linux logs reside?

Answer

```
/var/log
```

---

# 9. `/tmp`

Temporary files.

Applications store temporary data here.

Example

```
/tmp/file.txt
```

Files are usually deleted after reboot.

Anyone can write here.

Permissions

```
drwxrwxrwt
```

The **sticky bit (`t`)** ensures users can delete only their own files.

Interview Question

Why is `/tmp` world writable?

Answer

Because many applications need temporary storage, and the sticky bit protects users from deleting each other's files.

---

# 10. `/dev`

Everything in Linux is treated as a file, including hardware devices.

Examples

```
/dev/sda
/dev/sdb
/dev/null
/dev/random
/dev/tty
```

### Hard disk

```
/dev/sda
```

### First partition

```
/dev/sda1
```

### Null device

```
/dev/null
```

Anything written to it disappears.

Example

```bash
echo hello > /dev/null
```

No output.

Interview Question

What is `/dev/null`?

Answer

A special device that discards all data written to it.

---

# 11. `/proc`

A **virtual filesystem** created in memory.

It does not store real files.

Contains live system information.

Examples

```
/proc/cpuinfo
/proc/meminfo
/proc/uptime
```

CPU Information

```bash
cat /proc/cpuinfo
```

Memory

```bash
cat /proc/meminfo
```

Process

```
/proc/1234
```

contains information about process ID **1234**.

SREs frequently use `/proc` for debugging and monitoring.

---

# 12. `/opt`

Used for optional or third-party software.

Examples

```
/opt/google
/opt/oracle
/opt/tomcat
```

Large applications are often installed here.

---

# 13. `/boot`

Contains files required to boot Linux.

Examples

```
vmlinuz
initrd.img
grub
```

Without `/boot`, Linux cannot start.

---

# 14. `/lib` and `/lib64`

Contain shared libraries required by programs in `/bin` and `/sbin`.

Similar to DLL files in Windows.

Example

```
libc.so
```

---

# 15. `/media`

Automatically mounted removable devices.

Examples

```
USB drive
DVD
External HDD
```

---

# 16. `/mnt`

Temporary mount point for manually mounting filesystems.

Example

```bash
mount /dev/sdb1 /mnt
```

---

# 17. `/run`

Stores runtime information such as PID files, sockets, and lock files. Its contents are recreated each time the system boots.

---

# 18. `/srv`

Contains data served by services, such as web or FTP servers.

Example

```
/srv/www
```

---

# 19. `/sys`

Another virtual filesystem that provides information about hardware devices, drivers, and kernel settings. It's commonly used for hardware management and tuning.

---

# Frequently Asked Interview Questions

1. **What is the difference between `/` and `/root`?**

   * `/` is the top-level directory.
   * `/root` is the home directory of the root user.

2. **What is stored in `/etc`?**

   * System-wide configuration files.

3. **Where are Linux logs stored?**

   * Typically in `/var/log`.

4. **What is `/proc`?**

   * A virtual filesystem containing live process and kernel information.

5. **What is `/dev/null`?**

   * A special device that discards any data written to it.

6. **What is the difference between `/bin` and `/sbin`?**

   * `/bin` contains essential user commands.
   * `/sbin` contains system administration commands, generally intended for the administrator.

7. **What is the purpose of `/tmp`?**

   * Temporary storage for applications and users; contents may be cleared on reboot.

For an **SRE screening**, you should also be comfortable navigating these directories with commands like `cd`, `ls`, `pwd`, `find`, `du`, `df`, `cat`, and `tail`, and know where to look when troubleshooting issues (for example, checking `/var/log` for logs or `/proc` for process and system information).
